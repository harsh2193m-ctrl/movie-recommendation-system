# Movie Recommendation System

## Internship Project
A simple content-based movie recommendation system using Python, TF-IDF and cosine similarity.

## Features
- Reads movie title and genre data from CSV
- Converts genres into TF-IDF vectors
- Calculates cosine similarity
- Recommends similar movies

## How to run
```bash
pip install -r requirements.txt
python movie_recommender.py
```

Then enter a movie name when prompted.

## Technologies
Python, Pandas, Scikit-learn, TF-IDF, Cosine Similarity
